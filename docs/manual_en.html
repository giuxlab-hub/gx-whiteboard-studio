1. Launch and workspace

Start GX Whiteboard Studio from the Graphics application menu or run gx-whiteboard-studio in a terminal. Double-click an existing .gxwp or .gxwb document in Thunar to open it. F11 toggles fullscreen. The first toolbar contains essential controls; hide the secondary drawing toolbar when you need more room.

2. Wacom, drawing and navigation

Use the pen tip to draw. Tools include pen, highlighter, eraser, line, arrow, rectangle, ellipse and text. Vector annotations always remain above image and video boxes. Use Select to move and resize objects. Zoom +/− buttons also work with a stylus that has no wheel. Pan lets you navigate a canvas larger than the viewport. Right-drag pans the view; right-click on a selected media box opens its Z-order menu.

3. Images and boxes

Use Images → Add to build a thumbnail library. Select an image, press Insert, then draw the desired box with the pen. Alternatively drag a PNG, JPEG or WebP file straight from Thunar into the canvas, even during recording. Images are copied rather than moved and embedded in the project. Use eight handles to resize a selected box; adjust opacity, aspect ratio, fit or crop.

4. USB webcams and IP cameras

Under Cameras, select the USB device, capture resolution and FPS, then press Start and Insert box. The IP section accepts RTSP/HTTP/MJPEG URLs and labels sources as ip0, etc. Subnet discovery is limited to private networks and requires confirmation, but a camera with a public IP can be configured manually. Embedded credentials are not supported in this version. A detected camera may therefore still fail to stream if authentication is required.

5. Scenes and projects

Under Scenes, create, duplicate, rename and delete independent scenes. Each keeps its own ink, media and Z-order. Save complete multi-scene projects as .gxwp, or a single whiteboard as .gxwb. Images are embedded. Standard shortcuts: Ctrl+N for New Project, Ctrl+O for Open Project, Ctrl+S to Save. Undo/Redo history is independent for each scene during a session but is not serialized across application restarts.

6. Video and microphone recording

Press REC (Ctrl+Shift+R) to configure video profile, H.264 CPU/NVIDIA encoder, MKV destination, optional MP4 remux and microphone input. A PulseAudio microphone is only opened when recording starts. AAC audio accompanies the whiteboard video; Thunar windows and application controls are excluded. Press STOP REC to finish. Mute (Ctrl+Shift+M) is available during microphone capture. Allow FFmpeg to finalize before closing the application.

7. Diagnostics and recovery

Each recording creates a local sidecar file named name.mkv.recording-report.json with frame counts, dropped frames and encoder status. If MP4 conversion fails, a valid MKV remains available. Projects are saved atomically, with a previous-version .gxwp.bak backup when appropriate. Automatic recovery checkpoints are stored in XDG application data, and the application can offer recovery after an interruption. If the original project is corrupt, restore the backup into a new filename rather than overwriting either source.

Known limitations: a real-world continuous 30-minute recording is still awaiting routine-use validation. Authenticated IP cameras have not been validated. The program does not automatically upload data to the Internet.

9. Managing and cleaning the image library

The left gallery is a list of references to local image files. A thumbnail does not replace its source file. Images inserted into the canvas, however, are embedded in the saved project and remain usable when the original file is moved or deleted.

  1. Open Images, click Add and choose local PNG, JPG/JPEG or WebP files.
  2. To place an image, select its thumbnail, click Insert and draw a rectangle with the pen. You can also drag a picture directly from Thunar onto the canvas.
  3. To remove an unused entry, right-click the thumbnail itself and select Remove from library.
  4. The gallery entry disappears immediately and the new list is saved in preferences. The original file is never deleted.
  5. A removed image can be added again at any time. Images already inserted in your scenes remain unchanged.

Important: the canvas image properties panel also has a Remove button. It removes the selected box from the scene; the library menu removes only the gallery thumbnail.

10. Example workflow for a recorded lesson

  1. Create a new project and prepare the first scene and background.
  2. Insert charts or photos from Thunar, resize boxes with the eight handles and adjust media Z-order as needed. Ink will remain above media.
  3. Open REC, choose the MKV destination and microphone, then start recording. Only the composited canvas is captured, not the application controls or desktop windows.
  4. Draw with the Wacom and add more pictures while recording. You may switch scenes: the video follows the currently displayed scene.
  5. Use Mute if necessary. It affects this application's capture stream, not the whole system.
  6. Press STOP REC and wait for FFmpeg to finalize. Check the MKV file and its .mkv.recording-report.json sidecar.
  7. Save the editable project in .gxwp format as well.

11. Project backup and recovery

.gxwp stores a multi-scene project, while .gxwb is a single-board document. Project saves are atomic to prevent partial documents replacing valid files. The previous version can be retained as .gxwp.bak. If the primary project becomes invalid, the application can offer to restore its backup as a separate unsaved project. Save the recovered copy under a new name.

Automatic recovery checkpoints are stored under the user's XDG application data directory; this does not replace manual saving. Opening a project never automatically activates USB cameras, IP streams or microphones.

12. Preferences, shortcuts and diagnostics

Open Settings → Configuration to choose the user interface language and navigation behavior. Use Ctrl+B to show/hide the sidebar and Ctrl+Shift+T for the second drawing toolbar. Ctrl+0 fits the board to the viewport, while Ctrl++ and Ctrl+- control zoom.

For video troubleshooting, inspect the JSON sidecar next to the MKV for frame counts, dropped frames, encoder exit status and warnings. If MP4 conversion fails, a valid MKV is preserved. On critically low disk space, the program attempts to stop gracefully, but it cannot guarantee recovery after sudden disk exhaustion.

The NVIDIA NVENC encoder requires compatible working GPU drivers; otherwise CPU-based encoding is available. The real-world continuous 30-minute recording remains to be verified during normal use.
